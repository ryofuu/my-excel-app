# Worksheet構造をWorkbookRevisionの入力状態に含める

Worksheetの作成・削除・順序もCellContentと同じく`WorkbookRevision`を構成する入力状態として扱う。`WorkbookChangeSet.nextWorksheets`は個別のcreate/delete命令ではなく、変更後に存在するWorksheetの完全な順序付きSnapshotを表す。これにより、構造変更にも新しい動詞や専用Repositoryを増やさず、1つのRevision作成と1つのtransactionでCell変更と原子的に扱える。

Cell変更は対象Cellが重ならなければ古い`baseRevision`からも適用できる。一方、Worksheetの集合と順序はWorkbook全体の構造なので、`nextWorksheets`を含むChangeSetは最新Revisionだけに適用する。古い構造Snapshotを自動mergeすると、同時に作成・削除されたWorksheetを意図せず復活または消去するためである。

Workbookは最低1つのWorksheetを保持する。Worksheet削除時は、そのWorksheetに属するCellを同じtransactionで削除する。削除済みWorksheetを対象とする古いCell変更は`EditConflict`にする。CalculationSnapshotは引き続きWorkbook全体から導出し、UI projectionだけが選択中のWorksheetにCell・Trace・Errorを絞る。
