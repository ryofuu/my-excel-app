# 変更Cellだけを原子的に保存する

`Workbook` 全体をblobまたは全行置換で保存せず、`WorkbookChangeSet` が触れる疎なCell行だけを短いトランザクションで作成・更新する。CellContentの削除時も、内容を持たないtombstoneと最終変更版は残す。各Cellの最終変更版とChangeSetの基準版を比較する楽観的競合検出により、削除を含む同じCellへの並行変更は `EditConflict` とし、重ならない変更は同じ基準版からでも順に適用できるようにする。これによりSQLiteの書き込み直列化を受けても処理量をWorkbook全体ではなく変更Cell数に比例させ、将来共有DBへRepository実装を交換した場合も同じ競合規則を維持する。
