# Triage labels

このローカル issue tracker では、以下の標準ラベル文字列を `Status:` にそのまま記録する。

| 役割 | ラベル | 意味 |
| --- | --- | --- |
| 要評価 | `needs-triage` | メンテナーによる評価待ち |
| 情報待ち | `needs-info` | 報告者の情報待ち |
| Agent 実装可能 | `ready-for-agent` | 追加の人手判断なしに実装可能 |
| 人間実装待ち | `ready-for-human` | 人間による実装が必要 |
| 対応しない | `wontfix` | 実施しない |
